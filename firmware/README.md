# usbpd firmware (CH552P)

Build with SDCC (`brew install sdcc`), flash with [wchisp](https://github.com/ch32-rs/wchisp).

```
make          # build/usbpd.hex, build/usbpd.bin (8.2 KB of 14 KB)
make test     # host tests of src/logic.c and the OLED partial flush (src/oled.c against a panel model)
make screens  # ../docs/images/screen-*.png: what the firmware draws, rendered on the host
make flash    # hold CYCLE while plugging the board into USB, then run this
```

- `src/logic.c`: board-independent logic (voltage stepping, HUSB238 code tables, NTC table lookup, INA226 units,
  thermal trip, DataFlash settings log). Tested on the host by `test/test_logic.c`.
- `src/hw.c`: clock (16 MHz), pins, 1 ms timer, ADC, DataFlash, watchdog, bit-banged I2C.
- `src/oled.c`: 96x16 SSD1306/SSD1315 panel (init from the N069 panel datasheet, internal charge pump).
- `src/main.c`: behaviour (docs/requirements.md): restore saved voltage + ON state, ON/OFF, CYCLE through offered
  voltages only, over-temperature and over-current trips, both buttons 5 s = ROM bootloader.
- `src/ntc_table.h` is generated by `tools/gen_ntc_table.py` (R11 2.2k from VCC, NTC 10k B3380).

Bring-up checks on the real board: I2C clock (~100 kHz target), the panel image and orientation, NTC reading at room
temperature (~209 counts at 25 C), INA226 manufacturer ID 0x5449, then each PD voltage on a known charger.
